# UI 必要项清单（只改网页演示版，不改小程序）

> 原则：答辩打开的是**网页演示版**，小程序是产品载体、现场不打开。所以品牌化只做网页版。
> 分两档：**必要**（老师第一眼能看出品牌与口径一致，必做）+ **可选**（时间紧可后置）。

## 必要（品牌一致性 + 口径一致性）

1. **全局标题**：「物品管理」→「舍得 · AI 断舍离决策助手」。
2. **首页 slogan**：加一句产品主张，例如「不是替你扔掉东西，而是帮你想清楚」。
3. **六维命名统一**：
   - 是否重复 → 文案统一为「是否有重复/替代品」；
   - 占用空间 → 文案统一为「越省空间分越高」（避免“分越高越占地方”的歧义）。
4. **四选一文案统一**：留下 / 观察 / 出售或转赠 / 处理（前端 4 主按钮；内部 6 值不暴露）。
5. **来源声明**：页脚写「基于开源项目二次开发，仅课程作业使用」。
6. **三态看板**：首页明确显示 待决策 / 观察中 / 已处理 三态计数（对应 `/v5/observe/overview`）。

## 可选（锦上添花，可后置）

- logo / 品牌色 / 主题色统一；
- 页面加载动画、卡片美化；
- 六维条形图配色与图例；
- 空状态插画（“没有待决策物品”时）。

## 明确不做

- 不碰 `miniprogram/`（AGENTS.md 红线，避免部署风险）；
- 不改后端业务逻辑。
