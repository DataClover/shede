## 已拍板

1. **项目定位**：断舍离决策助手是主目标，不是收纳 App。PPT 明确「不是」：家庭库存管理 / 全屋收纳规划 / 单纯 AI 识物 / 强迫用户扔东西。
2. **主流程**：拍照 → AI 识别 → 4 问 → 六维分析 → 建议 → 用户决定（留下 / 观察 / 出售或转赠 / 处理）。
3. **分数口径**：六维加权总分，**分越高越该留**；阈值 ≥65 留、40–64 观察、<40 处理；观察箱 30 天。
4. **AI 三层 + 兜底**：识物 `glm-4v-flash`、决策 `glm-4-flash`、处理文案 AI；每个点都有规则兜底（`source=rule`），演示永不卡死。

## 已知 MVP 取舍（口径已对齐 Q&A 第 4、10 条，答辩可直接讲）

- `duplicate`（是否重复）目前用「有替代」答案近似填充（`v5_decision.py` 规则打分）。
- `space`（占用空间）AI 提示词为反转口径「分越高越不占地方」，前端建议页脚注已说明「分越高 = 越省空间」。
