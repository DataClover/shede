============================================================
  十二组《舍得》· AI 断舍离决策助手 — 如何打开
============================================================

【这是什么】
拍照识物 → 回答 4 个问题 → AI 给出六维分析与建议 →
用户四选一（留下 / 观察 30 天 / 出售转赠 / 处理）→ 观察箱跟踪。
后端 FastAPI + SQLite，网页演示版 + 微信小程序双端。

------------------------------------------------------------
【Windows 电脑】
1. 确认已装 Python 3.11 或更高（python.org 下载，
   安装时勾选 Add python.exe to PATH）
2. 双击「一键启动.bat」
3. 浏览器自动打开 http://localhost:8000 ，按页面引导走完整流程
4. 结束：运行「停止服务.bat」或在黑窗口按 Ctrl+C

【Mac 电脑】
1. 确认已装 Python 3.11+（终端执行 python3 --version 查看；
   没有则到 python.org 下载，或 brew install python@3.12）
2. 在本文件夹上右键 →「新建位于文件夹位置的终端窗口」
   （或打开终端后 cd 到本文件夹）
3. 执行：bash 一键启动-mac.command
   （也可以先 chmod +x 一键启动-mac.command 再双击运行）
4. 浏览器自动打开 http://localhost:8000

------------------------------------------------------------
【关于 AI 识别】
- backend/config.ini 里已填智谱 API key 则为真 AI 识别与打分；
- 未填 key 时自动进入演示模式（模拟识别 + 规则打分），
  流程完全一致、不会报错，断网也能演示。

【直接预览网页界面】
双击 web\index.html 可以看到界面样式；完整决策流程
需要先用上面的方式启动后端（接口在 localhost:8000）。

【小程序端】
miniprogram\ 为完整源码：微信开发者工具 → 导入项目 →
目录选 miniprogram → AppID 选「测试号」→
详情 → 本地设置 → 勾选「不校验合法域名…」。
（小程序需后端已启动，且电脑与手机在同一网络环境）

【目录说明】
backend\      Python 后端源码（入口 launch.py）
web\          网页演示版源码（html/css/js）
miniprogram\  微信小程序源码
汇报材料\     课堂展示 PPT
使用说明.md   更详细的操作与常见问题
